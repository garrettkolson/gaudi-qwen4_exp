# Grounding an Agent in This Vault Before Work

Grounding is read-only. It writes nothing. No agent starts a task from a prompt, a ticket, or its own memory.

1. **Read `CLAUDE.md` at the repository root.** *Check:* you can name the target stack and the non-negotiables — measured numbers beat inherited ones, reuse over re-derivation, correctness gates speed.
2. **Read `_system/INDEX.md`**, the map of every node with its summary and edge count. *Check:* if the graph looks suspect, run `python _system/lint_vault.py` first — an unresolved edge target breaks traversal downstream.
3. **Open the phase node** `custom/cust-phase-*.md` for the work at hand, then every `tasks/task-*.md` linked into it. *Check:* you can state the phase's exit criterion in one sentence; it becomes your definition of done.
4. **Walk `depends_on` edges upstream** from those tasks, recursively. *Check:* every dependency you reach is satisfied. An unmet dependency is a stop condition, not advice — P3 before P1, or P5 before P4b, is wasted work by design.
5. **Read the phase's `cust-risk-*.md` nodes**, plus every `hyp-*` and `question-*` node its tasks name. *Check:* you have noted which sit below 0.7 confidence. Those are unverified — you measure them, you do not assume them.
6. **Confirm the flags and pins** your phase inherits (`--enforce-eager`, `--kv-cache-dtype auto`, `VLLM_SKIP_WARMUP=true`, `--language-model-only`, the `c05d75a` pin) from their nodes rather than from habit. *Check:* nothing in your command line comes from the Gaudi 3 reference unless a measurement supports it.
7. **Only then start.** If you ran no skill, write no log node.

## When the graph contradicts the assignment

The graph wins until a human says otherwise. Do not silently diverge, and do not quietly edit the graph to match the assignment: record the conflict as a finding — a node or a report naming both positions and the ids involved — and stop for a human ruling. If the graph is simply missing something you need, that is also a finding: create the node with real edges to existing ids, or report the gap. Use `/query-vault` for specific questions rather than grepping the vault.

## Stop and escalate

Stop when step 4 finds an unmet dependency; when the graph and the assignment disagree on what is true or on the order of work; when you cannot tell whether a claim is evidence or inference; or when the linter reports breakage you did not cause.
